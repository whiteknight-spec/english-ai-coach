## 📌 Overview

**English AI Coach** is designed to accelerate spoken and written English fluency. It provides personalized, real-time conversational scenarios, instant grammar rectification, vocabulary suggestions, and confidence scores across simulated professional and everyday interactions.

---

## ✨ Features

- 💬 **Interactive Conversation Scenarios:** Contextual dialogues (e.g., tech interviews, workplace meetings, casual introductions).
- ✍️ **Instant Grammar & Tone Analysis:** Real-time feedback on sentence structure, lexical diversity, and polite professional tone.
- 🎨 **Modern Minimalist UI:** Built with React 19, Lucide icons, and Tailwind CSS v4 for ultra-clean readability.
- ⚡ **Ultra-Fast Performance:** Powered by Vite bundler and Oxlint for sub-millisecond linting and HMR.

---

## 🛠️ Tech Stack

- **Framework:** React 19 (Hooks, Functional Architecture)
- **Styling:** Tailwind CSS v4
- **Build Tool:** Vite
- **Iconography:** Lucide React
- **Linter:** Oxlint

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/whiteknight-spec/english-ai-coach.git
   cd english-ai-coach
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
